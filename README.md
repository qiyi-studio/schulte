# 舒尔特动态追踪

一个用来练注意力与视觉搜索的舒尔特方格训练小游戏。**数字会动** —— 这是它和常见静态版本的根本区别。



---

## 为什么要做

市面上的舒尔特方格几乎都是静态的。练几次之后,大脑就会记住数字的位置,靠记忆取巧而不是靠扫视,训练效果迅速衰减。

让数字动起来,记忆就失效了 —— 每一次都必须真的用眼睛去找。

## 五种模式

| 模式 | 说明 |
|---|---|
| **静态 · 热身** | 数字不动的传统舒尔特,用来建立个人基准用时 |
| **持续漂移** | 数字不断两两换位滑动,视线要一直咬住目标 |
| **定时重排** | 每隔几秒全盘瞬间打乱,考验快速重新定位 |
| **自由浮动** | 脱离格子,数字像气泡一样飘动反弹并互相避让 |
| **三环旋转** | 内中外三圈同心圆反向旋转,号码在三环之间全局打乱 |

三环旋转可选 **顺逆顺** 或 **逆顺逆**(外环 → 中环 → 内环)。相邻两环永远反向,交界处相对速度最快,也最容易跟丢。内环角速度更高,否则半径小会显得几乎不动。

## 其他功能

- **规模可调**:方格 3×3 – 7×7;三环模式 18 – 30 个号码,与同级方格的总数相当,成绩可横向对比
- **中心注视点**:显示中心十字与视幅环,要求视线钉在中心、靠余光搜索 —— 这是舒尔特训练本来在练的能力
- **反应时记录**:逐个数字记录点击间隔,给出均值与标准差。波动值比总用时更能反映专注的稳定性
- **成绩评定**:按「每格用时」折算,5×5 静态对应常见的 16 / 20 / 26 秒参考带,并按模式难度自动放宽
- **游戏化**:连击、积分、训练等级、9 个成就徽章
- **移动端适配**:窄屏下游戏区置顶,设置与成绩折叠到下方

> 评定标准仅供自我对比,不是临床或专业测评标准。

## 技术

单个 HTML 文件,**零依赖、零素材、零后端**。

- 原生 HTML / CSS / JavaScript,无框架、无构建步骤
- 格子、圆环、动画全部由代码绘制,不含任何图片资源
- 音效由 Web Audio API 实时合成,不含任何音频文件
- 成绩、积分、徽章存在浏览器 `localStorage`,不上传任何数据
- 字体来自 Google Fonts,加载失败时回退到系统字体,不影响使用

## 本地运行

下载 `index.html`,双击用浏览器打开即可。断网也能玩。
